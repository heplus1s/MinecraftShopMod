# 商店目录与交易操作调整

- 默认目录总计 993 项（比前版新增 888 项），新增项目可进行系统买卖。补入建筑变体、染色、功能、交通运输、红石、食物、工具、护甲等分类，市场读取同一分类与真实商店报价。特殊 NBT 变体、管理员专用物品仍不作为普通系统商品。
- 默认每笔最多 100 件；现有配置中的 `maxCount`（包括旧默认 64）保持不变。管理员可执行 `/shop admin maxcount 100` 调整，范围 1–2304；图形界面显示当前服务器上限。
- 价格仍逐件更新：买入上涨、卖出下降。拆单不会恢复旧价；批量总额不是首件单价乘数量。允许玩家通过采集、加工和价差取得收益，不承诺完全消除跨配方套利。
- 系统收购只能使用商店实际可用资金，不自动拨款、不透支，不增设日限额或冷却。
- 单项系统交易可用 `/shop admin trading minecraft:stone false` 关闭，`true` 重新开启；关闭不影响玩家市场挂牌。管理员调整起点后，已有成交价不会自动重置，须按需要明确执行原有 `anchor`／`reset` 指令。
- 旧目录一次升级到版本 3：只补新项目，不覆盖已有价格、名称或已保存的交易开关；不会重新加回此前删除的旧版项目。迁移前备份 `shopmod.pre-catalog-v3.json`。
- 私币收款支持银行允许的小数精度，不以央行券补零钱。挂单不足、无牌价或无法精确结算时拒绝本笔并显示原因。旧未完成混合收据仍按原记录恢复，不抹去已支付资产。
- 从收款确认页返回保留币种、类别、滚动位置与数量；成交详情按当前币种展示交易后的参考单价，而不是混用钻石等值。

验证说明：默认参考价是游戏经济配置，不是严格的全配方无套利价格。铜切石品的初始参考价已按 1 铜块可切出 4 切制铜 / 8 台阶修正；其他项目受市场供需动态影响。真实多人操作、画面与自定义配方仍需游戏内验证。

商品卡的“参考单价 / 静态估算”不是成交报价：估算仅为当前参考价乘数量，不含买卖差价及逐件价格变化。悬停价格可查看说明；个人币收款确认页显示服务器逐件计价后的实际收款。普通买卖仍直接执行并返回实际成交结果，本次未增设确认流程。
