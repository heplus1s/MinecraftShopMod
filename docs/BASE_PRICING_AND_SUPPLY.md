# 基础价、库存和短期买卖压力

## 基础价（pricingVersion 2）

只固定一个计价单位：**取得 1 件钻石的参照成本 = 1**。价格规则和实际报价分开：

1. **获取路线**：按地形采集、可量产、矿物、掉落、探索、首领等获取方式，估算进入成本、平均尝试次数和单位产量，再与钻石的参照成本相除。没有单件指定的默认价格。
2. **合成和加工**：已覆盖的原版路线按「材料总成本＋批次加工成本」除以产出量，有多个已知途径时采用成本最低的一条。可逆装箱保持配比；无限重复、不增加资源的操作不凭空增加商品价值。用于降低无成本套利的丝触矿石保护仍保留。
3. **数据边界**：这是可审查、可调整的游戏平衡模型，不是当前存档掉率或分钟数实测。未纳入配方的商品用获取类型或同类估算，不沿用旧手填价；不会自动解析所有原版或额外数据包配方。外部行情和库存都不改写基准。

## 基础库存、出入库和短期波动

- **实际库存**是商店可交付的件数。新账本为零；玩家交货或管理员有记录地备货后才有存量。零库存仍可收购，玩家不能买到。库存不足不拆单、不扣款。
- **基础/目标库存**按原版典型供给、可再生性和商品类别估算；不扫描地图。合格市场成交可调整目标，但不补货。
- **实际库存项**：库存充足时只小幅修正，普通区间最多上浮 5%、下调 3%。库存低于目标约一成（小库存商品最低按两件判定）才启用额外稀缺溢价，整体库存项上调不超过 18%。这些是模型边界，不是每笔涨跌。已有管理员配置 `stepFraction` 小于默认值时比例减弱，高于默认值也不会突破边界。
- **短期成交项**：系统买入与卖出的近期净流量分开于库存水平。玩家集中卖给商店产生向下压力，集中买走产生向上压力；同样的数量拉长时间，前几笔影响先衰减。每 5 分钟更新衰减，半衰期 10 分钟；短期项最多正负 4%，缺货附近的短期压价逐步减弱。只计实际完成的交易，不计预览、失败、备货或未成交挂单。
- **逐件报价**：同一时间窗口内，按实际库存及累计流量经过的各档逐件计价，短时间拆成几笔不增加收益（成交发生在不同时段、参考行情或结算条件改变时除外）。库存项与短期项不包括原有市场参考、买卖价差及货币换算。

## 已有服务器升级

默认保留已有锚价、市场报价、资金和库存数据。要更新旧目录的**默认**锚价，请备份配置和世界，再在 `config/shopmod.json` 顶层加 `"refreshDefaultAnchors": true`，用 `/shop admin reload` 或重启。旧版本 0 和 1 都有各自的原始比较基线：只更新 ID、默认名、原始默认价、启用状态都匹配的商品；自定义、已停用和删除的商品不动。升级前备份为 `shopmod.pre-pricing-v2.json`，完成后开关自动恢复为 false。已有世界存下的报价基准仍保留，管理员如需逐项换用新锚价，可使用原有 `reset` 操作。世界库存账本升级后不要直接回退旧 JAR。
